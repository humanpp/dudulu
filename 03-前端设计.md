**版本**：1.4
**定位**：定义 dudulu 前端的色彩、字体、组件、页面、交互、动效和响应式规范。
**依赖文档**：文档 0《项目总览》、文档 1《产品与数值设计》、文档 2《后端架构文档》

## 一、设计原则

dudulu 的界面不是工具，不是仪表盘，而是一个**让人愿意待着的地方**。六条原则：

1. **温暖而非冷峻**：暖色调、大圆角、柔和阴影。不用科技蓝、不用硬边框、不用锐角。
2. **安静而非喧闹**：大量留白、信息不拥挤、动效不抢注意力。界面退后，让对话成为主角。
3. **有生命感而非机械感**：数值变化有呼吸感，状态过渡是平滑的，不是跳变的。
4. **角色即界面**：切换角色时，整个界面的主色、氛围、细节都随之改变。用户感受到的是"换了一个人"，而不是"换了一套皮肤"。
5. **主动关怀有痕迹**：AI 主动发起对话时，界面要明确但不打扰地标记出来，让用户知道"这是它主动找我的"。
6. **不糊弄**：HTML/CSS/JS 可以做出专业级界面。每一个间距、每一个圆角、每一个过渡都经过设计。

### 3.2 切换实现

**注册 CSS 自定义属性**（支持过渡）：

```css
@property --accent-primary {
  syntax: '<color>';
  inherits: true;
  initial-value: #C4A882;
}
@property --accent-soft {
  syntax: '<color>';
  inherits: true;
  initial-value: #E8DDD0;
}
@property --accent-deep {
  syntax: '<color>';
  inherits: true;
  initial-value: #8B7355;
}

:root {
  transition: --accent-primary 600ms var(--ease-in-out),
              --accent-soft 600ms var(--ease-in-out),
              --accent-deep 600ms var(--ease-in-out);
}
```

**JS 切换**：

```javascript
// js/theme.js
export function applyCharacterTheme(theme) {
  const root = document.documentElement;
  root.style.setProperty('--accent-primary', theme.primary);
  root.style.setProperty('--accent-soft', theme.soft);
  root.style.setProperty('--accent-deep', theme.deep);
  root.style.setProperty('--accent-ghost', hexToRgba(theme.primary, 0.08));
}

function hexToRgba(hex, alpha) {
  const r = parseInt(hex.slice(1, 3), 16);
  const g = parseInt(hex.slice(3, 5), 16);
  const b = parseInt(hex.slice(5, 7), 16);
  return `rgba(${r}, ${g}, ${b}, ${alpha})`;
}
```

### 3.3 应用范围

| 元素             | 使用的主题色                              |
| :--------------- | :---------------------------------------- |
| 用户气泡背景     | `--accent-primary`                        |
| AI 气泡背景      | `--accent-soft`（随角色变色）             |
| 强调文字、标题   | `--accent-deep`                           |
| 按钮主色         | `--accent-primary`                        |
| 悬停背景         | `--accent-ghost`                          |
| 状态面板进度条   | `--accent-soft` → `--accent-primary` 渐变（与 5.2 实现一致） |
| 主动消息标签     | `--accent-deep`                           |
| 角色卡片选中边框 | `--accent-primary`                        |


**对比度要求（v1.1 新增）**：`soft` 是浅色，AI 气泡文字必须用 `--text-primary`，不得用白色；用户气泡以 `primary` 打底时文字用 `--text-inverse`。若某角色主题色使正文对比度低于 WCAG AA（4.5:1），由 `utils/color.js` 的 `ensureContrast()` 自动加深背景，而不是改文字颜色——既保住"角色即界面"，也不牺牲可读性。

### 7.2 流式输出（SSE）

| 阶段         | 反馈                                 |
| :----------- | :----------------------------------- |
| 等待首 token | 显示打字指示器（三个跳动圆点）       |
| 流式输出中   | 文字逐字出现，末尾显示脉动光标       |
| 输出完成     | 光标消失，气泡高度平滑过渡到最终高度 |
| 输出中断     | 显示"重新生成"按钮                   |

### 7.3 状态数值更新

当 WebSocket 推送状态更新时：

1. 状态面板中对应维度的条形图宽度平滑过渡（`--duration-slow`）
2. 数值数字用滚动动画更新（从旧值滚动到新值）
3. 如果变化幅度超过阈值（如 PLE 变化 > 0.15），面板有轻微的呼吸动画（缩放 1.0 → 1.02 → 1.0）
4. 变化幅度取自 `state_update` 推送里的 `delta`（存在 `store.lastDelta`）。**没有 delta 就没有呼吸动画**——别让前端自己拿新旧值相减，推送顺序和沉淀改写都会让它误判

### 7.4 主动消息接收

当 WebSocket 推送 `proactive_message` 时：

1. 如果用户当前在该角色的聊天页：消息直接插入聊天区域，带主动标签
2. 如果用户在其他页面：在角色卡片上显示小红点，侧边栏对应角色项也显示小红点
3. 红点在用户进入该角色聊天页后消失
4. 移动端角色列表收在侧边栏里，用户看不见卡片红点，因此**顶部导航栏的角色名旁**要显示同样的小红点（数据源是 `store.unreadProactive`，多角色时取总数）
5. 红点只表示"有主动消息没看过"，不显示条数；同一角色多条未读合并为一个红点

### 7.5 角色切换

| 阶段         | 反馈                                               |
| :----------- | :------------------------------------------------- |
| 点击角色卡片 | 卡片放大 1.02，边框变主题色                        |
| 切换中       | 主题色平滑过渡（600ms），聊天区域淡出              |
| 切换完成     | 聊天区域淡入，显示新角色的消息和状态，主题色已更新 |

### 7.6 错误处理

| 场景         | 反馈                                   |
| :----------- | :------------------------------------- |
| 网络断开     | 顶部显示细条横幅，主题色变灰，自动重连 |
| API 错误     | 气泡标红，显示错误信息和重试按钮       |
| 认证过期     | 跳转登录页（api.js 拦截 401 时清 token），登录后回到原页面 |
| 角色加载失败 | 显示骨架屏，3 秒后显示错误占位         |

```javascript
// js/api.js
const BASE_URL = '/api';

async function request(path, options = {}) {
  const token = Alpine.store('app').token;
  const headers = {
    'Content-Type': 'application/json',
    // 用户时区随请求上报，后端同步进 users.timezone 供 quiet_hours 判定（文档 2 第 3.11 节）；
    // 兜底 'Asia/Shanghai' 与后端缺省值是同一个值，不是两套兜底
    'X-Timezone': Intl.DateTimeFormat().resolvedOptions().timeZone || 'Asia/Shanghai',
    ...options.headers,
  };
  if (token) {
    headers['Authorization'] = `Bearer ${token}`;
  }

  const response = await fetch(`${BASE_URL}${path}`, {
    ...options,
    headers,
  });

  if (response.status === 401) {
    Alpine.store('app').clearToken();
    window.location.hash = '#/login';
    throw new Error('认证过期');
  }

  if (!response.ok) {
    const error = await response.json().catch(() => ({}));
    throw new Error(error.detail || '请求失败');
  }

  return response.json();
}
```

```javascript
      headers: {
        'Content-Type': 'application/json',
        'Authorization': `Bearer ${token}`,
        'X-Timezone': Intl.DateTimeFormat().resolvedOptions().timeZone || 'Asia/Shanghai',
      },
      body: JSON.stringify({
        character_id: characterId,
        session_id: sessionId,
        message: message,
      }),
    });

    if (!response.ok) {
      throw new Error('请求失败');
    }

    const reader = response.body.getReader();
    const decoder = new TextDecoder();
    let buffer = '';

    while (true) {
      const { done, value } = await reader.read();
      if (done) break;

      buffer += decoder.decode(value, { stream: true });
      const lines = buffer.split('\n\n');
      buffer = lines.pop();

      for (const line of lines) {
        if (!line.trim()) continue;
        const eventMatch = line.match(/^event: (.+)$/m);
        const dataMatch = line.match(/^data: (.+)$/m);
        if (!eventMatch || !dataMatch) continue;

        const event = eventMatch[1];
        const data = dataMatch[1];

        if (event === 'token') {
          onToken(data);
        } else if (event === 'done') {
          onDone(JSON.parse(data));
        } else if (event === 'error') {
          onError(new Error(JSON.parse(data).message));
        }
      }
    }
  } catch (error) {
    onError(error);
  }
}
```

### 9.4 WebSocket 管理（`js/ws.js`）

```javascript
// js/ws.js
class WebSocketManager {
  constructor() {
    this.ws = null;
    this.reconnectAttempts = 0;
    this.maxReconnectAttempts = 5;
    this.handlers = new Map();
  }

  connect() {
    const token = Alpine.store('app').token;
    if (!token) return;

    const protocol = window.location.protocol === 'https:' ? 'wss:' : 'ws:';
    this.ws = new WebSocket(`${protocol}//${window.location.host}/ws/events`);

    this.ws.onopen = () => {
      this.ws.send(JSON.stringify({ type: 'auth', token }));
      this.reconnectAttempts = 0;
    };

    this.ws.onmessage = (event) => {
      const data = JSON.parse(event.data);

      if (data.type === 'state_update') {
        // 后端推的是完整状态 + delta（见文档 2 第 6.11 节），这里只取三层，
        // 不把 type / character_id / delta 混进 state 对象
        const store = Alpine.store('app');
        if (data.character_id === store.currentCharacter?.id) {
          store.state = {
            expression: data.expression,
            internal: data.internal,
            affective: data.affective,
          };
          store.lastDelta = data.delta || null;   // 呼吸动画的判据，别丢掉
        }
        this._emit('state_update', data);         // data 里带着 delta，订阅方要用
      } else if (data.type === 'proactive_message') {
        // 不是当前角色：只打未读红点，不往聊天区塞消息
        const store = Alpine.store('app');
        if (data.character_id !== store.currentCharacter?.id) {
          store.markProactiveUnread(data.character_id);
        }
        this._emit('proactive_message', data);
      }
    };

    this.ws.onclose = () => {
      if (this.reconnectAttempts < this.maxReconnectAttempts) {
        const delay = Math.pow(2, this.reconnectAttempts) * 1000;
        setTimeout(() => {
          this.reconnectAttempts++;
          this.connect();
        }, delay);
      }
    };
  }

  on(event, handler) {
    if (!this.handlers.has(event)) {
      this.handlers.set(event, []);
    }
    this.handlers.get(event).push(handler);
  }

  _emit(event, data) {
    for (const handler of this.handlers.get(event) || []) {
      handler(data);
    }
  }

  disconnect() {
    if (this.ws) {
      this.ws.close();
      this.ws = null;
    }
  }
}

export const wsManager = new WebSocketManager();
```

```javascript
import { wsManager } from '../ws.js';

import { generateId } from '../utils/id.js';

export function chatApp() {
  return {
    messages: [],
    input: '',
    isSending: false,
    isStreaming: false,
    streamingContent: '',
    character: null,
    sessionId: null,

    async init() {
      const characterId = getCurrentCharacterId();
      this.character = await api.getCharacter(characterId);
      Alpine.store('app').setCurrentCharacter(this.character);

      const session = await api.createSession(characterId);
      this.sessionId = session.session_id;

      this.messages = (await api.getRecentMessages(characterId)).messages;
      Alpine.store('app').clearProactiveUnread(characterId);   // 进入聊天页即清除该角色的红点
      wsManager.connect();
      wsManager.on('proactive_message', (data) => {
        if (data.character_id === characterId) {
          this.messages.push({
            id: generateId(),
            role: 'assistant',
            content: data.message,
            timestamp: data.timestamp,
            isProactive: true,
          });
          this.scrollToBottom();
        }
      });
    },

    async send() {
      if (!this.input.trim() || this.isSending) return;

      const userMessage = {
        id: generateId(),
        role: 'user',
        content: this.input.trim(),
        timestamp: new Date().toISOString(),
      };
      this.messages.push(userMessage);
      const content = this.input.trim();
      this.input = '';
      this.isSending = true;
      this.isStreaming = true;
      this.streamingContent = '';

      await sendMessageStream({
        characterId: this.character.id,
        sessionId: this.sessionId,
        message: content,
        onToken: (token) => {
          this.streamingContent += token;
          this.scrollToBottom();
        },
        onDone: (data) => {
          this.messages.push({
            id: generateId(),
            role: 'assistant',
            content: this.streamingContent,
            timestamp: new Date().toISOString(),
          });
          Alpine.store('app').state = data.state;
          this.isStreaming = false;
          this.streamingContent = '';
          this.isSending = false;
          this.scrollToBottom();
        },
        onError: (error) => {
          this.isSending = false;
          this.isStreaming = false;
          showError(error.message);
        },
      });
    },

    onEnter(event) {
      // Shift+Enter 交给浏览器默认行为（换行）；单独按 Enter 才发送。
      // 注意不能在模板里写 @keydown.enter.prevent，否则 Shift+Enter 的换行也被拦掉。
      if (event.shiftKey) return;
      event.preventDefault();
      this.send();
    },

    scrollToBottom() {
      this.$nextTick(() => {
        this.$refs.messages.scrollTop = this.$refs.messages.scrollHeight;
      });
    },
  };
}
```

```javascript
      const result = await api.previewValidate({ profile: this.profile });
      this.validationIssues = result.issues;
      this.profileValid = result.valid;
    },

    nextStep() {
      if (this.currentStep < this.steps.length - 1) {
        this.currentStep++;
      }
    },

    prevStep() {
      if (this.currentStep > 0) {
        this.currentStep--;
      }
```
